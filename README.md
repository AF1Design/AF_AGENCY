# منصة AF AGENCY الرسمية (اي اف ايجنسي)

> **"TURNING YOUR DREAMS INTO REALITY"**
> منصة ويب تفاعلية حديثة مصممة بنهج الهواتف أولاً (موبايل فيرست) لتحويل زوار الإعلانات إلى عملاء ومبيعات مؤكدة مع مخصص باقات تفاعلي وربط بقاعدة بيانات سوبابيس واستضافة فيرسل.

---

## المميزات والخدمات المدمجة

1. **مخصص الباقات التفاعلي (الخدمات الرقمية):**
   - **تصميم وتطوير المواقع:** صفحات هبوط إعلانية، مواقع شركات، متاجر إلكترونية، أنظمة مخصصة.
   - **الهوية البصرية:** تصميم لوجو، هوية متكاملة، بروفايل شركة، حزمة سوشيال ميديا.
   - **التسويق الرقمي:** إعلانات ميتا (فيسبوك وإنستغرام)، تيك توك، جوجل، إنتاج المحتوى.
2. **أكاديمية الكورسات والتدريب:**
   - دبلومة الجرافيك ديزاين الشاملة وسوق العمل.
   - كورس أدوات الذكاء الاصطناعي (AI) الإبداعي.
   - الباقة المزدوجة الذهبية.
3. **معرض سابقة الأعمال:** مع إمكانية الفلترة السريعة وعرض نتائج بالأرقام (+45% مبيعات، 380+ عميل).
4. **نافذة إتمام الطلب والتحويل التلقائي للواتساب:**
   - حفظ بيانات العميل في جدول (leads) داخل سوبابيس فوراً.
   - إنشاء رسالة واتساب منسقة ومجهزة بجميع اختيارات العميل وملاحظاته وإرسالها برابط مباشر لمسؤول المبيعات.
5. **السرعة والأداء:**
   - مبني بتقنية Next.js مع React و Tailwind CSS.
   - خطوط عربية حديثة (تجوّل وكايرو) وألوان مستوحاة 100% من الشعار (الأسود الفاحم، الأصفر النيون الكناري، والأبيض).

## طريقة التشغيل محلياً

1. تثبيت الحزم:
   ```bash
   npm install
   ```

2. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
   ثم افتح المتصفح على: `http://localhost:3000`

3. فحص البناء النهائي:
   ```bash
   npm run build
   ```

## خطوات ربط قاعدة بيانات سوبابيس (Supabase)

1. ادخل على حسابك في [Supabase](https://supabase.com) وأنشئ مشروعاً جديداً.
2. افتح **SQL Editor** داخل لوحة تحكم سوبابيس.
3. انسخ محتويات ملف `supabase_schema.sql` الموجود في جذر هذا المشروع، والصقها واضغط **Run**. سيتم إنشاء جدول `leads` وصلاحيات الأمان تلقائياً.
4. اذهب إلى **Project Settings -> API** وانسخ:
   - رابط المشروع (`Project URL`)
   - المفتاح العام (`anon public key`)
5. افتح ملف `.env.local` وضع القيم كالتالي:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   NEXT_PUBLIC_WHATSAPP_NUMBER=201012345678
   ```

## خطوات الرفع والنشر على فيرسل (Vercel)

1. قم برفع المشروع على حسابك في GitHub (أو استخدم تطبيق GitHub Desktop).
2. افتح [Vercel](https://vercel.com) وسجل دخولك.
3. اضغط على **Add New Project** واختر مستودع المشروع `AF`.
4. في قسم **Environment Variables**، أضف المتغيرات الثلاثة:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `NEXT_PUBLIC_WHATSAPP_NUMBER`
5. اضغط **Deploy**، وسيكون موقعك حياً على الإنترنت في أقل من دقيقتين مع شهادة أمان مجانية وسرعة فائقة في جميع أنحاء العالم.
